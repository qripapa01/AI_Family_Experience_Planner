# AI Family Experience Planner

**부모는 교육적 가치를 선택하고, 아이는 재미있는 경험을 선택합니다.**

AI Family Experience Planner는 초등 교과과정을 뒤에서 활용해 앞으로 최대 6개월 안에 배우게 될 내용을 바탕으로 가족 나들이를 추천하는 체험형 서비스입니다.

아이에게는 공부·예습이 아니라 **모험, 발견, 사진, 배지** 중심의 경험을 제공하고, 부모에게는 해당 나들이가 어떤 교과와 연결되는지 조용히 안내합니다.

## 핵심 기능
- 학년/학기 선택
- 현재 진도 또는 표준 진도 설정
- 최대 6개월 Experience Window 기반 추천
- 아이용: 오늘의 모험 이야기, 발견 미션, 사진 기록, 모험 배지
- 부모용: 교과 연결 정보, 예상 학습 시기, 추천 이유
- Learning + Local: 주변 지역상권 연계

## 핵심 철학
- 선행학습처럼 느껴지지 않게
- 의무감 없이 즐겁게
- 나들이가 먼저, 학습효과는 자연스럽게
- 수업에서 나중에 ‘내가 봤던 거다!’라는 연결 경험을 만들기
