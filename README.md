# 교과ON (Gyogwa-ON)

**교과서에서 배우기 전에, 세상에서 먼저 만나다.**
가족 나들이가 먼저, 배움은 자연스럽게 따라오도록.

🔗 **라이브 데모:** https://qripapa-ai-family-20260817.web.app

교과ON은 앞으로 최대 6개월 안에 배우게 될 초등 교과 내용을 바탕으로, 아이가 공부처럼 느끼지 않는 **재미있는 가족 나들이**를 추천하고 — 그 경험이 이후 학교 수업과 자연스럽게 연결되도록 돕는 AI 체험학습 추천 서비스입니다.

아이에게는 **모험·발견·사진·배지** 중심의 경험을, 부모에게는 그 나들이가 어떤 교과와 연결되는지, 언제 배울 내용인지를 조용히 안내합니다.

> **부모는 교육적 가치를 선택하고, 아이는 재미있는 경험을 선택합니다.**

## 핵심 차별점 — '어디'가 아니라 '언제'
기존 서비스가 "어디로 갈까?"를 찾게 해준다면, 교과ON은 **"우리 아이가 언제 가야 학습과 가장 잘 연결되는가"**를 알려줍니다. 비교적 곧 배울 내용은 **🔥 지금이 좋은 시점(골든타임)**으로 강조합니다.

## 핵심 기능 (MVP)
- 학년 · 학기 · 아이 관심사(역사·문화 / 과학·자연 / 야외·생태) 선택
- 최대 6개월 Experience Window 기반 추천 + **골든타임(가까운 시점) 강조**
- 아이용: 오늘의 모험, 발견 미션, 사진 기록, 모험 배지
- 부모용: 교과 연결 정보, 예상 학습 시기, 추천 이유
- Learning + Local: 체험 장소 주변 식당·전통시장·공방·서점 등 지역상권 연계

## 기술 구성
- 순수 정적 웹앱 (HTML · CSS · Vanilla JS), 별도 빌드 불필요
- Firebase Hosting 배포
- `index.html` / `main.js` / `style.css`

## 로컬 실행
```bash
# 저장소를 받은 뒤
open index.html   # 또는 브라우저로 index.html 열기
```

## 배포 (Firebase Hosting)
```bash
firebase deploy --only hosting
```

## 로드맵
- 실제 초등 교육과정 데이터 구조 확대
- 수도권 실제 체험 장소 30~50개 데이터 구축
- 위치 기반 거리·이동시간 필터, 지도 연동
- 아이 관심사 기반 AI 개인화 추천 및 코스 자동 생성
- 방문 완료·사진 기록, 방문 후 대화·복습
- 지역 소상공인 연계 및 지자체 B2G 교육·상권 사업

## 참고
본 저장소는 **모두의 창업 프로젝트 2기 지원용 MVP**입니다. 현재 장소·교과·시점 데이터는 서비스 개념 검증을 위한 **데모 데이터**이며, 실제 출시 전 최신 교육과정·시설 운영정보·위치정보 등을 검증·연동할 예정입니다.
